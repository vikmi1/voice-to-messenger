# Voice-to-Messenger

Наговори — получи готовое сообщение. Приложение превращает спонтанную речь в чистый,
готовый к отправке текст (выбор тона, свой стиль по прежним сообщениям, эмодзи,
оформление списком, опциональный перевод) за 2–3 касания:
надиктовал → **Копировать / Поделиться / Сохранить заметку**.

Главная боль, которую закрывает продукт: не печатать длинные сообщения вручную и не слать
голосовые, но и не воевать с ChatGPT, который добавляет к ответу лишние фразы.

## Структура

- **`backend/`** — тонкий Flask-прокси: держит API-ключи, применяет системный промпт и стили,
  управляется через веб-панель. Провайдеры LLM (OpenAI-совместимые и Anthropic)
  переключаются без правки кода.
  Распознавание речи — на устройстве или серверный Whisper (`/api/transcribe`).
- **`android/`** — нативное приложение (Kotlin + Jetpack Compose): экран диктовки,
  заметки, настройки и кнопка-пузырь поверх мессенджеров. Интерфейс на русском,
  немецком и английском. Плюс скрытая админ-панель: те же настройки бэкенда
  правятся прямо с телефона.

## Архитектура

```
[Android] микрофон → ASR (на устройстве / серверный Whisper) → текст
        → тумблер «Локально / Сервер» → готовый текст → Копировать / Поделиться / Заметка
        ↳ пузырь поверх других приложений повторяет тот же путь
[Backend] /api/transcribe (Whisper) · /api/process (LLM + системный промпт)
        · /api/options (стили и языки) · /admin (панель) · /admin/api/* (та же панель с телефона)
```

Подробности — в `backend/README.md`. План разработки — в утверждённом дизайн-документе.
