# Voice-to-Messenger

Наговори — получи готовое сообщение. Приложение превращает спонтанную речь в чистый,
готовый к отправке текст (выбор тона, свой стиль по прежним сообщениям, эмодзи,
оформление списком, опциональный перевод) за 2–3 касания:
надиктовал → **Копировать / Поделиться / Сохранить заметку**.

Главная боль, которую закрывает продукт: не печатать длинные сообщения вручную и не слать
голосовые, но и не воевать с ChatGPT, который добавляет к ответу лишние фразы.

## Структура

- **`backend/`** — тонкий Flask-прокси: держит API-ключи, применяет системный промпт и стили,
  управляется через веб-панель. Провайдеры LLM (OpenAI-совместимые и Anthropic)
  переключаются без правки кода; у каждого своя модель обработки текста и своя модель
  распознавания речи, а панель подсказывает подобранные варианты с ценами.
  Распознавание речи — на устройстве или серверный Whisper (`/api/transcribe`).
  Каждый запрос к провайдеру пишется в журнал расхода: сколько токенов и секунд аудио
  он стоил (пока только наблюдение, ничего не тарифицируется).
- **`android/`** — нативное приложение (Kotlin + Jetpack Compose): экран диктовки,
  живой перевод, заметки, настройки и кнопка-пузырь поверх мессенджеров. Между экранами
  ходят нижней панелью — она одна на всё приложение. Интерфейс на русском,
  немецком и английском. Одна диктовка ограничена пятью минутами: по достижении
  предела запись останавливается сама и спрашивает — отправить или удалить.
  Плюс скрытая админ-панель: те же настройки бэкенда правятся прямо с телефона,
  вкладка расхода, и раздел игр (2048, таблицы Шульте, струп-тест) — занять руки,
  пока модель думает.

## Живой перевод

Отдельный экран: микрофон слушает собеседника и переводит на выбранный язык — текстом
на экране и голосом в наушник. Язык говорящего определяется моделью, вручную его не
задают; выбирается только язык, **на** который переводить (русский, немецкий,
английский, итальянский, китайский).

Одной модели «звук → перевод» у провайдеров нет, поэтому связка из трёх:

```
микрофон (PCM 16 кГц) → WebSocket /api/live → Voxtral Realtime (потоковое распознавание,
    определяет язык сам) → куски текста → LLM-перевод каждой фразы → Voxtral TTS → наушник
```

Что удерживает расход: тишина в модель не отправляется (ворота по громкости на
устройстве), сессия закрывается сама по истечении предела из админ-панели (по умолчанию
10 минут), а если говорят на языке перевода — перевод не вызывается вовсе. Расход
пишется в тот же журнал тремя строками на сессию: `live_stt`, `live_translate`, `live_tts`.

Ограничение: перевод живёт, пока открыт экран. В фоне система забирает микрофон у
приложения, поэтому экран на время сессии не гаснет.

## Архитектура

```
[Android] микрофон → ASR (на устройстве / серверный Whisper) → текст
        → тумблер «Локально / Сервер» → готовый текст → Копировать / Поделиться / Заметка
        ↳ пузырь поверх других приложений повторяет тот же путь
        ↳ живой перевод: микрофон → WebSocket → текст и озвучка в наушник
[Backend] /api/transcribe (Whisper) · /api/process (LLM + системный промпт)
        · /api/live (живой перевод, WebSocket) · /api/options (стили и языки)
        · /admin (панель) · /admin/api/* (та же панель с телефона)
        ↳ каждый запрос к провайдеру → журнал расхода (токены и секунды аудио, сырыми)
```

Подробности — в `backend/README.md`. План разработки — в утверждённом дизайн-документе.
